# 一次性脚本（留档，不参与日常使用）

这里放的是**当时用过一次就不再需要**的迁移/改名脚本。留着是为了让后来的人能看懂
某次批量改动到底改了什么、改了多少处——比在提交信息里描述更准确。

| 脚本 | 做了什么 | 何时用过 |
|---|---|---|
| `rename-cli-cmd.mjs` | 把文档里的 `cxstudy <子命令>` 批量改成 `cxa <子命令>`（8 个文档 17 处），自带自检（包名未被误伤、无重复替换、残留 0） | 2026-11-27 CLI 主命令改名 |
| `fix-cli-usage.mjs` | 改 `src/cli.mjs` 的 USAGE 标题与 8 个命令位，加别名说明 | 同上 |

**不要删它们**，除非确认那段历史已经不需要追溯。

**也不要跑它们**——里面的字符串是当时的，现在跑会破坏当前内容。
